# نسيم الرافدين

منصة الرصد الفضائي للدفاع المدني في العراق.

تعمل الواجهة على Netlify وتستدعي وظائف الخادم في `/api/data/` لجلب بيانات NASA FIRMS وSentinel-5P عبر Copernicus Data Space والطقس وجودة الهواء عبر Open-Meteo. لا تحتاج إلى سكربتات Python أو ملفات بيانات محلية.

أضف المتغيرات التالية في إعدادات البيئة للخادم ثم أعد النشر:

- `FIRMS_MAP_KEY`
- `CDSE_CLIENT_ID`
- `CDSE_CLIENT_SECRET`
- `MAPTILER_KEY`

لا تضف قيم المفاتيح إلى ملفات المشروع. تُجلب بلاطات MapTiler عبر وظيفة الخادم دون إرسال المفتاح إلى المتصفح.

القراءات تُجلب عند فتح الصفحة، مع تخزين استجابات البيانات مؤقتاً في شبكة CDN لمدة 30 دقيقة. إعادة تحميل الصفحة تعيد طلب البيانات. فشل أي مصدر يظهر رسالة دون تعطيل بقية المصادر. الغازات تعرض أحدث بكسل متاح ضمن ثلاثة أيام؛ قد تغيب بعض القراءات بسبب السحب أو تأخر الأقمار. تاريخ الغازات هو وقت الجلب، وليس توقيت مرور القمر لكل بكسل.

النقاط الحرارية تشمل مصادر صناعية ومشاعل؛ تصنيف المصدر الثابت تقديري من تكرار الموقع خلال ثلاثة أيام. عتبات الغازات نسبية وتحتاج معايرة ميدانية؛ الأقمار تقيس عمود الغازات ولا تقيس التركيز عند الأرض. البيانات ليست بديلاً عن التحقق الميداني.

للتحقق من الكود: `node --check app.js` و`npx tsc --noEmit --module nodenext --moduleResolution nodenext --target es2022 --skipLibCheck netlify/functions/*.mts`.
